# wastewateR

### Installation

`devtools::install_github("micom-hub/wastewateR")`

### Usage

This package needs `tidyverse` installed & loaded in order to function.

The QAQC module is meant to serve as a flexible, automated method to apply data quality checks on ddPCR results from wastewater-based epidemiology tests, directly from machine to analysis. 


### Current Contents

##### QAQC Module 

 - Fifteen functions from original working space (https://github.com/cmu-delphi/MiCOM-Wastewater) with names changed
 - One wrapper function for SARS-CoV-2 N1 testing
